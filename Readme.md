# DL20_LinkTest：DL20 无线串口收发测试工程

本工程复制自 `code/RP27_Cboard`，只用于验证 DL20 链路，**不属于 RP27_Dart**，也不能用于比赛。

和模板相比有三处改动：

| 文件 | 改动 |
|---|---|
| `Application/TaskLayer/community_task.c` | 测试逻辑：发帧、收帧解析、回显、统计、LED 指示、USB 打印 |
| `Core/Src/usart.c`、`My_C.ioc` | USART1 波特率改为 115200（模板原为 2000000，ioc 里写的是 921600，两处不一致） |
| `Application/DeviceLayer/imu_xrobot.c` | 删除外接 IMU 的 `USART1_rxDataHandler`，USART1 改给 DL20 用 |

## 1. 硬件与接线

DL20 排针从左到右依次是 VCC、TXD（模块输出）、RXD（模块输入）、GND，以模块丝印为准。

| DL20 | C 板 USART1（丝印 UART2） |
|---|---|
| VCC | 5V 或 3.3V（模块支持 3.0~5.5 V） |
| TXD | PB7（USART1_RX） |
| RXD | PA9（USART1_TX） |
| GND | GND |

- TX 和 RX 要交叉接。
- 根据原理图，DL20 的 TXD 输出经 2N7002 上拉到 VCC，所以 VCC 接 5V 时 TXD 输出的就是 5V。PB7 是 5V 容忍（FT）引脚，可以直接接；但如果方便，优先用 3.3V 供电。
- C 板丝印 UART2 对应 USART1 是根据大疆资料记忆得出的，接线前请对照 C 板手册确认丝印和线序。

## 2. DL20 配置（按键）

两只模块都配成：**115200 波特率、同一信道，一只点对点 A 端，一只点对点 B 端**。

1. 断电，按住按键再上电，四个 LED 快速循环闪烁后松开，进入设置模式。
2. 短按切换波特率，切到 115200（按说明书图示：两个绿灯亮、两个红灯灭）。
3. 长按到 LED 循环闪烁后松开，进入信道设置；短按切换信道（16 个），两只模块要设成同一个。
4. 长按进入模式设置，短按切换：两红 = A 端，两绿 = B 端，四灯全亮 = 广播（按说明书图示）。
5. 长按到 LED 循环闪烁后松开，常亮 2 s 后保存；中途断电则不保存。

配置成功后两只模块同时上电：A 端亮一红一绿，B 端亮两绿；有数据发出时，按键同侧的红灯会闪。

## 5. 测试

### 方法 A：单板 + 电脑（推荐先做）

1. DL20(A) 接 C 板，DL20(B) 接 USB 转 TTL（VCC、GND、TX 接 RX、RX 接 TX）。
2. 电脑安装 USB 转 TTL 芯片的驱动（CP2102 的驱动见 `无线串口说明书/CP2102驱动`）。在设备管理器里确认出现了 COM 口。
3. 用串口助手（如 `无线串口说明书/串口调试助手/UartAssist.exe`）打开这个 COM 口，115200 8N1。
4. 应该每 200 ms 收到一行，例如 `$DL20,3A7F,123,0*5C`，序号每行加 1。
5. 勾选“发送新行”（或在末尾手动加回车换行），发送 `hello`，应收到 `ECHO,3A7F:hello`。

### 方法 B：双板

1. 两块 C 板各接一只 DL20（一只 A 端、一只 B 端）。
2. 上电后看 LED：蓝灯每 200 ms 翻转一次 = 正在发送；绿灯翻转 = 收到对端有效帧；红灯常亮 = 1 s 内没有收到有效数据。
3. 通过 USB 线把任意一块 C 板接到电脑，会出现一个 USB 虚拟串口，每秒打印一行统计：

```
id=3A7F peer=91C2 link=1 tx=500 peer_rx=498 lost=0 dup=0 ack=497 pc=0 bad=0 self=0 ovf=0/0 bytes=...
```

   也可以在 Keil 调试时把 `dl20_stat` 加进 Watch 窗口查看。

### 判读

| 字段 | 含义 | 正常情况 |
|---|---|---|
| `link` | 1 s 内是否收到过有效数据 | 1 |
| `peer_rx` / `lost` | 收到的对端帧数 / 按序号推算的丢帧数 | `lost` 为 0 或极少（点对点模式有确认重发） |
| `ack` | 对端回报收到的本板最新序号 | 紧跟本板 `tx`，说明**双向**都通 |
| `bad` | 校验或格式错误的帧数 | 0 |
| `self` | 收到本板自己 ID 的帧数 | 0；大于 0 说明 TX/RX 短接或形成回环 |
| `ovf` | 超长行 / 接收缓冲溢出 | 0/0 |
| `bytes` | USART1 收到的总字节数 | 持续增加；一直为 0 说明线没接上、接反，或波特率不对 |

建议先近距离测，再拉远或加遮挡，并记录 `lost` 的变化。

### 常见问题

- 串口助手里全是乱码：DL20 的波特率不是 115200。
- 完全没有数据：TX/RX 没有交叉接；两只模块不在同一信道；两只都配成了 A 端（或都是 B 端）。
- 收到的数据“延迟”或成批到达：DL20 会把串口数据打包后再无线发送，这是正常现象。协议按行解析，不依赖到达时刻。
